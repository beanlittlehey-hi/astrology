# 月栖卡牌日记小程序 V0.1

这是基于 `原型图/玄学App原型图V0.1.html` 实现的微信小程序高保真可点通版本。

## 打开方式

1. 安装并打开微信开发者工具。
   成功标志：能看到“导入项目 / 新建项目”入口。

2. 选择“导入项目”，项目目录选择本仓库根目录：`/Users/shimiao/Documents/Codex/玄学`。
   成功标志：开发者工具识别到 `project.config.json`，并显示小程序根目录为 `miniprogram/`。

3. AppID 可先选择测试号或使用 `touristappid`。
   成功标志：模拟器打开后出现“月栖卡牌日记”启动页。

4. 点击“预览”并用微信扫码。
   成功标志：手机微信里能打开同一套小程序页面。

## 已实现范围

- 模拟登录与注销入口。
- 首页、个人侧边栏、今日单张牌、问题方向、牌阵推荐、洗牌抽牌、结果页。
- 情绪日记自动保存、情绪轨迹、日记详情。
- 水晶疗愈推荐、测算结果后的水晶首饰推荐卡、定制预售方案表单与私域入口占位弹窗。
- 本地存储：登录状态、日记记录会保存在微信开发者工具或真机本地缓存里。
- 云开发接入：已预留微信云开发配置、云函数和云数据库读写封装；填写环境 ID 并上传云函数后即可启用。

## 当前边界

- 不接真实手机号登录。
- 云开发环境尚未开通时，后端读写会自动回退到本地缓存。
- 不接支付或外部私域账号。
- 定制预售仅生成本地模拟方案，暂不创建真实订单。
- 塔罗结果使用本地内容库和规则生成，适合 MVP 验证和高保真演示。
- 内容仅供娱乐、情绪陪伴和自我探索参考，不构成医疗、心理诊断、法律或投资建议。
